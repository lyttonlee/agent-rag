## 1. 定位与范围（标准制定方视角）

### 1.1 一句话定位
我方提供一套**公文 RAG 引擎平台**，并**制定集成标准**（接口、字段、密级/权限枚举、模型接入）；各部署方/第三方按标准适配，既可沿用我方默认模型栈，也可接入自有算力中心的模型；我方负责解析、切片入库、检索推理、模板库与导出下载。

### 1.2 职责边界（我方标准，第三方适配）

| 职责 | 归属 | 说明 |
|---|---|---|
| 接口规范 / 字段标准 / 密级权限枚举 / 模型接入标准 | **我方制定** | 第三方须适配（第 3 章、接口文档） |
| 文档解析（格式适配配置） | 我方 | 配置驱动，免改代码 |
| 切片入库（含密级/权限标签存储） | 我方 | 标签格式按我方标准 |
| 混合检索（执行密级/权限过滤） | 我方 | 过滤规则按我方标准服务端强制 |
| 推理生成（引用溯源、敏感词后处理） | 我方 | — |
| **模板库维护** | **我方** | 我方管理；第三方可导入提供模板样式 |
| **导出下载接口** | **我方** | 按模板渲染导出 docx/pdf，提供下载 |
| 配置中心 / 运维台 | 我方 | 敏感词、格式适配、模板、模型接入配置 |
| 文档数据（带密级/权限） | 第三方提供 | **格式按我方标准** |
| 模型（算力中心） | 第三方可选提供 | 符合我方标准模型接口；或用我方默认栈 |
| 组织架构 / 用户认证 / 权限主数据 | 第三方 | 数据层；格式按我方标准 |
| 前端调用 | 第三方 | 调用我方检索/生成/导出接口 |

### 1.3 多部署级别与模型解耦
- 不同部署级别（如总部/分支、不同客户实例）可配置各自的**模型接入配置（ModelProfile）**。
- 模型后端三类，统一经 `ModelProvider` 抽象：① 我方默认本地栈（Qwen3）② 开发期云端 API ③ **部署方算力中心（符合我方标准模型接口）**。
- 切换仅配置，业务零改动；生产启动自检拒绝云端 Provider 出网。

## 2. 沿用基线（已确认，不再复述理由）

- 部署：完全私有化内网；规模 200 用户 / 20 并发 / 20 万文档；种子语料 30 篇（实测 96.7% 有文字层，OCR 非瓶颈）。
- 文种首批 8 类：通知/通报/报告/请示/函/纪要/决定/意见。
- 格式：docx/pdf/wps(转)/ofd(二期)；字体已有授权。
- 架构：模块化单体（FastAPI + Vue3 运维台，Docker Compose）。
- 检索：**PostgreSQL + pgvector + zhparser**（单库统一元数据+BM25+向量）。
- 模型默认栈：Qwen3-32B-INT4(生成) + Qwen3-Embedding-4B(离线) + Qwen3-Reranker-0.6B(在线)。
- 信创：仅 OS/DB 国产（GPU 可 N 卡）；对象存储（本地文件系统 / S3 兼容）；涉密不出网三层防护。

---

## 3. 我方制定的标准（摘要，全文见接口文档）

1. **文档元数据字段标准**：`external_id, title, doc_type, issuer, doc_no, publish_date, security_level, permission_tags[], owner_org, source_system`。
2. **密级枚举（我方标准，六级）**：`PUBLIC`(非密,1.0) / `INTERNAL`(内部,2.0) / `COMMERCIAL`(普通商密,2.3) / `CORE_COMMERCIAL`(核心商密,2.7) / `CLASSIFIED`(密级,3.0) / `TOP_SECRET`(机密,4.0)（第三方映射自身分级；历史四级代码与中文名自动归一，见迁移 0015）。
3. **权限标签格式**：`scope:<type>:<value>`，`type∈{dept,role,user,group}`；检索时 `caller_scope[]` 同格式，交集匹配 + 密级上限判定可见性。
4. **标准模型接入接口**：兼容 OpenAI 风格的 Chat / Embeddings / Rerank 端点（详见接口文档第 6 章），部署方算力中心实现或加兼容网关即可接入。
5. **接口契约**：`/v1/documents`、`/v1/retrieve`、`/v1/generate`、`/v1/export`、`/v1/templates`、`/v1/config/*`（详见接口文档）。

## 4. 部署拓扑（BOM 同 V1.1，模型后端可外指算力中心）

```
[内网] 第三方系统/前端 ──标准API──> 我方接入网关 ──> 业务模块(解析/检索/生成/模板/导出/配置)
                                                    │
                        ┌───────────────────────────┼───────────────────┐
                        ▼                           ▼                   ▼
                  PG+pgvector+zhparser         对象存储（本地文件系统 / S3 兼容）             模型后端(可外指)
                  (密级/权限标签)              (原文/附件)       · 我方本地Qwen3栈
                                                        · 部署方算力中心(标准接口)
GPU BOM：最低48GB(L40S/双4090)，建议80GB(A100/H100/昇腾910B)；仅OS/DB国产→N卡可买
```

## 5. 实施里程碑

| 阶段 | 目标 | 门禁 |
|---|---|---|
| M0 环境 | 国产 OS + PG+pgvector+zhparser + 对象存储（本地文件系统 / S3 兼容） + 默认模型栈起通 | env_smoke 全绿 |
| M1 入库质量 | 30 篇种子入库，切片/向量/检索 | 检索准确率 ≥85% |
| M2 检索+过滤 | 混合检索 + 密级/权限下推（按我方标准） | 越权/超密级召回 = 0 |
| M3 推理+溯源 | 8 类文种 + 生成 + 引用溯源 + 敏感词后处理 | 格式合规 ≥95%；幻觉 ≤3% |
| M4 模板+导出 | 模板库 + 导出下载接口（docx/pdf） | 导出保真达标 |
| M5 模型解耦 | 标准模型接口接入部署方算力中心 | 替换模型零代码改动 |
| M6 标准联调 | 与第三方按我方标准联调 | 字段/密级/权限/模型端到端通过 |

## 6. 风险（更新）

| 风险 | 等级 | 对策 |
|---|---|---|
| R1 语料质量 | 高 | 上下文前缀 + 自定义词典 + M1 复盘 |
