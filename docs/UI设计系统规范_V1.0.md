# 企业公文知识库平台 · UI 设计系统规范 V1.0

> 交付物：`web/index.html`（高保真可交互原型）+ 本文档（设计令牌与组件标准）
> 设计定位：**政务 / 企业级可信感 + 克制精密的科技感**
> 配套技术栈（生产实现）：Vue3 + Vite + TypeScript；本规范全部采用系统字体栈，**零外部字体依赖**，契合纯内网部署。

---

## 1. 设计原则

| 原则 | 落地方式 |
|---|---|
| **可信优先** | 政务场景第一要务是"稳、准、安全"，不炫技。科技感来自精密的栅格、数据可视与状态反馈，而非霓虹与渐变文字。 |
| **唯一主色** | 仅一个品牌主色（智蓝 `#3D7EFF`）。语义色（绿/琥珀/红）**只用于密级与状态**，不作装饰，避免色彩噪音。 |
| **公文气质** | 品牌与大标题用**思源宋体**（公文传统的仿宋/宋体气质），UI 正文用**思源黑体**，形成有意图的文化呼应。 |
| **信息密度** | 页面铺满视口、少留白浪费；用分隔线、节奏间距而非无脑卡片堆叠来组织信息（密度高时不套卡片）。 |
| **状态即界面** | 每个操作都有加载 / 空 / 错误 / 触觉反馈；涉密与权限拦截有明确视觉表达。 |
| **零外部依赖** | 字体与图标全部系统栈 / 内联 SVG，不引用任何公网 CDN，满足内网合规。 |

## 2. 设计令牌（Design Tokens）

### 2.1 色彩

**底色（深墨蓝，非纯黑）**
| 令牌 | 值 | 用途 |
|---|---|---|
| `--ink-950` | `#070B14` | 应用最底层背景 |
| `--ink-900` | `#0A0F1C` | 应用背景 |
| `--ink-850` | `#0D1424` | 侧栏 / 抽屉背景 |
| `--ink-800` | `#111B30` | 卡片表面 |
| `--ink-750` | `#16223B` | 悬浮 / 二级表面 |
| `--ink-700` | `#1C2A47` | 进度条底 / 悬浮 |
| `--ink-600` | `#243456` | 头像渐变 / 开关底 |

**线条**：`--line rgba(150,178,220,.10)` · `--line-2 .18` · `--line-strong .30`

**文本**：`--t1 #EAF1FB`（主）· `--t2 #A6B7D2`（次）· `--t3 #6E81A2`（弱）· `--t4 #4E6081`（极弱）

**品牌（唯一主色）**
| 令牌 | 值 | 用途 |
|---|---|---|
| `--brand` | `#3D7EFF` | 主操作、激活态、链接、关键数据 |
| `--brand-600` | `#2F6AE0` | 主按钮 hover |
| `--brand-soft` | `rgba(61,126,255,.14)` | 激活底 / 焦点环 |
| `--brand-line` | `rgba(61,126,255,.42)` | 激活边框 |
| `--brand-glow` | `rgba(61,126,255,.35)` | 顶部辉光（克制） |

**公文红（仅印章 / 文头）**：`--seal #C0392B` · `--seal-soft rgba(192,57,43,.14)`

**语义色（仅密级 / 状态）**
| 令牌 | 值 | 语义 |
|---|---|---|
| `--ok` | `#2FBF71` | PUBLIC / 健康 / 通过 |
| `--warn` | `#F2B53C` | RESTRICTED / 警告 / 待审 |
| `--danger` | `#E5484D` | SECRET / 错误 / 拦截 |
| `--info` | `#3D7EFF` | 信息（复用品牌） |

### 2.2 密级徽标规范（强制）

密级是本产品最高频的语义标识，必须严格对应：

| 枚举 | 徽标类 | 点色 | 语义 |
|---|---|---|---|
| `PUBLIC` | `.b-public` | 绿 | 公开，可全员检索 |
| `INTERNAL` | `.b-internal` | 蓝 | 内部，限本单位 |
| `RESTRICTED` | `.b-restricted` | 琥珀 | 受限，限角色/部门 |
| `SECRET` | `.b-secret` | 红 | 秘密，限保密组 |

### 2.3 字体

| 角色 | 字体栈 | 用途 |
|---|---|---|
| 展示 / 品牌 / 大标题 | `"Source Han Serif SC","Noto Serif SC","Songti SC","SimSun",serif` | Logo、视图标题、公文纸标题、文种名 |
| UI 正文 | `"PingFang SC","Microsoft YaHei","Source Han Sans SC","Noto Sans SC",system-ui,sans-serif` | 全部界面文字 |
| 等宽（数据 / ID） | `ui-monospace,"SF Mono","JetBrains Mono",Menlo,Consolas,monospace` | 指标数字、文号、切片号、日志 |

> 字体选择是有意图的：宋体呼应公文传统、黑体保证 UI 可读性、等宽保证数据对齐。**不引入任何外部 Web 字体**。

### 2.4 间距 / 圆角 / 阴影

- 间距基准 4px：`--s1..--s16`（4/8/12/16/20/24/32/40/48/64）
- 圆角：`--r-s 8` · `--r 12` · `--r-l 16` · `--r-xl 20` · `--r-pill 999`
- 阴影：`--sh-1`（静止）· `--sh-2`（悬浮）· `--sh-3`（纸张/抽屉）
- 动效曲线：`--ease cubic-bezier(.16,1,.3,1)`；尊重 `prefers-reduced-motion`

## 3. 应用外壳（App Shell）

| 区域 | 规范 |
|---|---|

## 4. 组件库

### 4.1 按钮（Button）
- `.btn` 默认（描边）、`.btn.primary`（智蓝填充 + 辉光阴影）、`.btn.ghost`（透明）、`.btn.sm`
- 规则：主操作唯一突出；同屏主按钮不超过 1 个；图标 + 文字，hover 微亮。

### 4.2 卡片（Card）
- `.card` 表面 + 1px 线 + 极淡阴影；`.card.hov` 悬浮上浮 3px 并提亮边框。
- **高密场景不用卡片套卡片**：用 `divide-y` 分隔线或间距区隔（见表格、日志）。

### 4.3 徽标 & 状态（Badge / Status）
- 密级徽标见 2.2；状态点 `.st`：`.d.ok/.warn/.danger/.run`（run 为呼吸动画，仅用于"运行中"）。
- 语义徽标 `.b-ok/.b-warn/.b-danger` 用于启用 / 待审 / 失败等。

### 4.4 表格（Table）
- 透明背景、次文本表头、行 hover 提亮；数字 / ID 用等宽；进度条 `.bar` 内嵌单元格。
- 密级列始终带色点，权限标签用等宽展示 `scope:dept:政研室`。

### 4.5 表单（Form）
- 标签在上、错误在下、输入块 `gap:7px`；聚焦态智蓝边框 + 4px 焦点环。
- 开关 `.sw`（IOS 风，智蓝激活）；下拉 / 文本域同风格。

### 4.6 抽屉（Drawer）
- 右侧 440px 滑入 + 半透明遮罩；用于文档详情、配置项展开，避免跳转打断主流程。

### 4.7 数据可视化（手绘 SVG，无第三方库）
- 折线（检索准确率趋势，带渐变填充）、环形（文种分布 / 资源水位仪表盘）、进度条、状态点。
- 全部内联 SVG，零依赖；颜色走令牌。

### 4.8 公文纸（Paper）
- 起草视图右侧"白纸"：`#FBF8F2` 暖白、双线文头（公文红）、宋体正文、缩进 2em、红色引用上标、旋转印章。
- 这是"科技感界面里的一张真实公文"，提供强对比与语境真实感。

## 5. 视图规范（7 大视图）

| 视图 | 核心内容 | 关键模式 |
|---|---|---|
| **平台概览** | KPI 条（文档/切片/准确率/问答）+ 检索趋势折线 + 系统健康 + 文种环形 + 最近接入 | Bento 栅格、手绘图表 |
| **文档库** | 接入筛选 chips + 文档表（文号/文种/密级/权限/状态/切片/进度）+ 详情抽屉 | 表格 + 抽屉 |
| **智能检索** | 全局检索框 + 过滤 chips + 左结果卡（高亮命中）+ 右问答卡（引用上标 + 引用列表 + 校验标签） | 双栏 feed + 溯源 |
| **智能起草** | 左文种选择（8 类）+ 中公文纸 + 右 AI 辅助（溯源/格式/敏感词/模型） | 三栏 + 纸张 |
| **模板库** | 8 文种卡片，缩略图用 CSS 渲染"迷你公文纸 + 印章" | 4 列网格 |
| **配置中心** | 标签：密级标准 / 权限标签 / 敏感词 / 模型接入 / 格式适配器 | 标签页 + 表单 |
| **运维台** | 资源仪表盘（GPU/显存/队列/容量）+ 模型状态 + 安全态势 + 入库任务 + 日志流 | 仪表盘 + 日志 |

## 6. 状态规范

| 状态 | 实现 |
|---|---|
| 加载 | 骨架微光（后续实现）、按钮 loading 态 |
| 空态 | `.empty` 居中图标 + 引导文案，不出现空白死页 |
| 错误 | `.b-danger` 徽标 + 行级错误色 + 重试入口 |
| 触觉反馈 | 按钮 `:active` 缩放、卡片悬浮上浮、抽屉滑入 |
| 权限拦截 | 检索结果明确标注"可见范围"，超密级请求在日志中以 `SECURITY` 黄色记录 |

---

## 7. 无障碍（WCAG AA）

- 文本对比度 ≥ 4.5:1（主文本 `#EAF1FB` on `#0A0F1C` 远超标准）。
- 所有图标按钮带 `title`；交互元素可见焦点环（智蓝 4px）。
- 动效全部包在 `prefers-reduced-motion` 判断内，关闭后无动画。
- 触控目标 ≥ 38px（按钮 38px、图标钮 38px）。

## 8. 与 Vue3 生产实现的组件映射

| 原型元素 | Vue3 组件建议 |
|---|---|
| 应用外壳 | `<AppShell>` + `<SideNav>` + `<TopBar>` + `<GlobalSearch>` |
| 卡片 / KPI | `<Card>` / `<KpiCard>` |
| 表格 | `<DataTable>`（含密级渲染插槽） |
| 密级徽标 | `<SecurityBadge level="INTERNAL">` |
| 抽屉 | `<Drawer>` + 遮罩 teleport |
| 图表 | `<LineChart>` / `<DonutChart>` / `<GaugeRing>`（SVG 封装） |
| 公文纸 | `<DocPaper>`（接收模板 + 引用数据） |
| 配置标签页 | `<Tabs>` + 各配置子组件 |
| 状态点 | `<StatusDot state="run">` |

> 原型为设计与评审用途（零构建、可直接预览）；生产实现按上表拆为 Vue3 单文件组件，令牌直接映射为 CSS 变量或 `:root` 主题。

## 9. 待评审确认项

1. **主题**：当前为深墨蓝暗色（科技感强、护眼）；是否需同步提供**浅色主题**（公文起草场景部分用户偏好白底）？建议采用"暗色外壳 + 浅色公文纸"混合，已在本原型落地。
2. **公文红使用边界**：当前仅用于印章 / 文头 / 密级红标，确认无品牌冲突。
3. **密度**：当前偏中高密度（铺满视口），如需更"大气"可适度降密度。
4. **字体落地**：生产环境需确认目标机已装思源宋体 / 黑体或随包分发字体文件（内网无法在线拉取）。
