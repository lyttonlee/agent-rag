## 1. 通用约定

### 1.1 Base 与协议
- Base：`https://<部署域内网>/v1/`
- 协议：HTTPS（内网）；字符集 UTF-8；时间 ISO-8601（`2025-10-13T08:30:00+00:00`）。
- 开放端点（无需认证）：`POST /v1/auth/login`、`POST /v1/auth/clients/register`、`GET /health`、`/docs`、`/redoc`、`/openapi.json`。
- 其余全部 `/v1/*` 业务端点**强制双模认证**（见 1.2）。

### 1.2 双模认证（2026-10-13 起强制执行）

| 调用方 | 认证头 | 说明 |
|---|---|---|
| 用户（运维台/控制台） | `Authorization: Bearer <JWT>` | `POST /v1/auth/login` 换取，默认 12 小时有效（`jwt_expire_hours` 可调） |
| 第三方系统（机器对机器） | `X-API-Key: sk-xxxx` | `POST /v1/auth/clients/register` 注册获取，**明文仅返回一次**，服务端仅存 sha256 哈希 |

- 双模依赖 `get_caller`：同一组接口同时服务两种调用方；**Bearer JWT 优先**，否则解析 X-API-Key；任一通过即放行。
- 两种凭证都缺失 → `401 {"detail":"需要登录凭证（Bearer JWT）或 API Key（X-API-Key）"}`。

**调用方视图（Caller）与权限管控：**

| 字段 | 类型 | 说明 |
|---|---|---|
| kind | string | `user` / `client` |
| id | string | 用户 ID 或 client_id |
| role | string | 用户角色（`admin`/`operator`/`viewer`）或 `client` |
| max_clearance | enum | 可检索最高密级。用户按角色映射：`admin`→`SECRET`，其余→`INTERNAL`；客户端取注册额度 |
| scopes | string[] \| null | 第三方能力域白名单（用户为 null=不限制） |

- **密级压低（cap_clearance）**：请求体声明的 `max_clearance` 不得超过调用方额度，超出自动压低到额度值（服务端强制，不信任客户端声明）。
- **能力域（scopes）**：`chat` / `retrieve` / `documents` / `spaces` / `conversations` / `templates` / `config` / `audit` / `ops`，或 `["*"]` 全开。缺失对应域 → `403`。
- **管理端点**（客户端管理）额外要求 admin 用户（`caller.kind == "user" and role == "admin"`），否则 `403`。

### 1.3 响应包格式（当前实现）

- **成功**：直接返回该端点的响应 Model JSON（无外层包装）。字段类型见各章「响应 Model」表。
- **失败**：`{"detail": "<错误描述>"}` + 对应 HTTP 状态码（见第 14 章错误码）。
- 流式端点（SSE）：`Content-Type: text/event-stream`，事件为 `data: {json}\n\n`，事件结构见 7.3 / 7.4。
- 文件下载端点：直接返回文件流（`Content-Disposition: attachment`）。
- > 注：`{code/message/data/trace_id}` 统一包装列为后续版本标准，当前版本未启用；联调请按上述实际格式处理。

## 2. 我方制定的字段与枚举标准

### 2.1 文档元数据标准（接入必带）
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| external_id | string | 是 | 第三方主键（幂等依据） |
| title | string | 是 | 标题 |
| doc_type | string | 是 | 文种：通知/通报/报告/请示/函/纪要/决定/意见 |
| issuer | string | 否 | 发文机关 |
| doc_no | string | 否 | 文号 |
| publish_date | string | 否 | ISO 日期（`2025-03-01`） |
| security_level | enum | 否（默认 `INTERNAL`） | 见 2.2 |
| permission_tags | string[] | 否（默认 `[]`） | 见 2.3 |
| owner_org | string | 否 | 归属组织 |
| source_system | string | 否 | 来源系统标识 |
| space_id | string | 否 | 所属文档空间 ID；缺省归入默认空间 |
| content | string | 否 | 内联正文；与 `content_ref` 二选一 |
| content_ref | string | 否 | 存储对象键：local 模式为相对路径，s3 模式为对象键；与 `content` 二选一 |
| chunk_strategy | enum | 否（默认 `paragraph`） | 切分策略：`paragraph` 按段落 / `fixed` 定长 / `sentence` 按句 / `section` 按章节 |
| chunk_size | int | 否（默认 800） | 单切片最大字符数，范围 64–4000 |
| chunk_overlap | int | 否（默认 80） | 相邻切片重叠字符数，范围 0–1000 |

### 2.2 密级枚举（我方标准）
`PUBLIC`(公开) / `INTERNAL`(内部) / `RESTRICTED`(受限) / `SECRET`(秘密/涉密)
权重：`PUBLIC`=0 < `INTERNAL`=1 < `RESTRICTED`=2 < `SECRET`=3（服务端 `SECURITY_WEIGHT`）。
> 第三方将自身分级**映射**到上述四级；检索以我方枚举判定上限。

### 2.3 权限标签格式（我方标准）
元素：`scope:<type>:<value>`，`type ∈ {dept, role, user, group}`。
示例：`["scope:dept:总部", "scope:role:公文员"]`。
检索可见条件：`chunk.permission_tags && caller_scope`（数组交集非空）且 `chunk.security_level <= max_clearance`（服务端 WHERE 下推，非生成后过滤）。

### 2.4 能力域枚举（第三方客户端注册用）
`chat`（问答）/ `retrieve`（检索）/ `documents`（文档接入）/ `spaces`（空间管理）/ `conversations`（会话）/ `templates`（模板库）/ `config`（配置）/ `audit`（审计）/ `ops`（运维）；`["*"]` 表示全部。

## 3. 认证接口（/v1/auth）

### 3.1 用户登录（换 JWT）
`POST /v1/auth/login` — **开放端点**

**请求体（LoginReq）：**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 用户名 |
| password | string | 是 | 口令（pbkdf2-sha256 26 万迭代校验，恒定时间比较） |

**响应 Model（LoginResp，HTTP 200）：**
| 字段 | 类型 | 说明 |
|---|---|---|
| access_token | string | JWT（HS256，payload：sub/username/role/iat/exp） |
| token_type | string | 固定 `"bearer"` |
| expires_in | int | 有效期（秒，默认 43200 = 12h） |
| user | UserResp | 用户信息（见下） |

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "bearer",
  "expires_in": 43200,
  "user": {
    "id": "u-001", "username": "admin", "display_name": "系统管理员",
    "role": "admin", "enabled": true, "last_login_at": "2026-10-13T08:30:00+00:00"
  }
}
```
> 失败：`401 {"detail":"用户名或口令错误"}`（不区分账号不存在与口令错误，防枚举）。账号禁用同样 401。

### 3.2 当前登录用户
`GET /v1/auth/me` — 需 `Authorization: Bearer <JWT>`

**响应 Model（UserResp，HTTP 200）：**
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 用户 ID |
| username | string | 用户名 |
| display_name | string | 显示名（缺省空串） |
| role | string | `admin` / `operator` / `viewer` |
| enabled | bool | 是否启用 |
| last_login_at | datetime \| null | 最近登录时间 |

> 用途：前端启动时校验登录态。`401` 表示未登录/令牌过期。

### 3.3 第三方客户端注册（返回一次性 API Key）
`POST /v1/auth/clients/register` — **开放端点**（注册即拿凭证）

**请求体（ClientRegisterReq）：**
| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| name | string | 是 | — | 客户端名称（建议接入系统名，便于审计） |
| scopes | string[] | 否 | `["chat","retrieve"]` | 能力域白名单，见 2.4 |
| max_clearance | enum | 否 | `INTERNAL` | 可检索最高密级额度 |

**响应 Model（ClientRegisterResp，HTTP 200）：**
| 字段 | 类型 | 说明 |
|---|---|---|
| client_id | string | 客户端 ID（`cli-` 前缀） |
| name | string | 客户端名称 |
| key_prefix | string | API Key 前缀（如 `sk-ab12…`），仅供核对 |
| scopes | string[] | 生效的能力域 |
| max_clearance | string | 密级额度 |
| enabled | bool | 是否启用 |
| expires_at | datetime \| null | 过期时间（当前版本恒为 null=不过期） |
| created_by | string | 创建者（自助注册为 `self-register`） |
| last_used_at | datetime \| null | 最近使用时间 |
| created_at | datetime \| null | 创建时间 |
| **api_key** | string | **API Key 明文，仅此一次返回，请立即保存** |

```json
{
  "client_id": "cli-9f2c1a0b3d4e5f60",
  "name": "OA 公文系统",
  "key_prefix": "sk-Ab3xK9...",
  "scopes": ["chat", "retrieve"],
  "max_clearance": "INTERNAL",
  "enabled": true,
  "expires_at": null,
  "created_by": "self-register",
  "last_used_at": null,
  "created_at": "2026-10-13T09:00:00+00:00",
  "api_key": "sk-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"
}
```
> 注册成功后，业务调用只需带 `X-API-Key: sk-XXX`。滥用防护由 scopes/max_clearance 额度约束 + 管理端禁用兜底。

### 3.4 客户端列表（admin）
`GET /v1/auth/clients` — 需 **admin 用户 JWT**

**响应 Model（ClientResp[]，HTTP 200）：** 字段同 ClientRegisterResp，但**不含 api_key**（永不明文返回）。

### 3.5 禁用 / 启用客户端（admin）
`POST /v1/auth/clients/{client_id}/disable` / `POST /v1/auth/clients/{client_id}/enable`
— 需 **admin 用户 JWT**

**路径参数：** `client_id`（string，客户端 ID）
**响应 Model（ClientResp，HTTP 200）：** 更新后的客户端信息。
> 禁用后该客户端持有的 API Key **立即失效**（应急止血用）；`404` 表示客户端不存在。

## 4. 文档空间（/v1/spaces）

> 文档空间是知识库的逻辑分区（支持层级，类似文件夹）。文档归属空间，检索/问答可按 `space_ids` 限定范围。默认空间固定 ID `spcdefault0000000000000000000000`。
>
> **空间所有权（2026-10-14 起强制执行）**：
> - 第三方应用/运维用户**创建的空间仅创建者本人可见、可上传、可检索**（用户与第三方同规则）；
> - 默认空间为 system 公共空间：所有人可见、可上传；
> - 他人空间：列表/详情不可见（`404`，不暴露存在性）、上传 `403`、纳入检索 `403`；
> - 空间的 owner 由服务端按调用方身份写入（用户 JWT → `user`；X-API-Key → `client`），不接受客户端指定。

### 4.1 创建空间
`POST /v1/spaces` — 需认证（scopes 含 `spaces` 或 `*`）

**请求体（SpaceCreate）：**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | string | 是 | 空间名称（1–128 字符） |
| code | string | 是 | 空间编码（唯一，第三方稳定标识，1–64 字符） |
| description | string | 否 | 描述（≤512 字符） |
| parent_id | string \| null | 否 | 父空间 ID；缺省为根级空间（须为默认空间或本人空间） |

**响应 Model（SpaceResp，HTTP 201）：**
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 空间 ID |
| name / code / description | string | 基本信息 |
| is_default | bool | 是否默认空间 |
| parent_id | string \| null | 父空间 ID（null=根级） |
| owner_type | string | `system`=公共（默认空间）/ `user` / `client` |
| owner_id / owner_name | string \| null | 创建者标识与展示名（system 为 null） |
| is_mine | bool | 当前调用方是否为创建者（前端据此开放编辑/删除） |
| can_upload | bool | 当前调用方是否可向该空间上传 |
| doc_count | int | 实时文档数 |
| chunk_count | int | 实时切片数 |
| created_at / updated_at | datetime \| null | 时间戳 |

> `409` 空间编码已存在 / 父空间不存在（404）/ 无权在他人空间下建子空间（403）。

### 4.2 空间列表 / 详情
- `GET /v1/spaces` → `SpaceResp[]`（默认空间置顶，含实时统计；**仅返回默认空间 + 本人创建的空间**）
- `GET /v1/spaces/{space_id}` → `SpaceResp`（不存在或非本人空间均 `404`）

### 4.3 更新空间
`PUT /v1/spaces/{space_id}` — 需认证

**请求体（SpaceUpdate，均选填）：** `name`（1–128）、`description`（≤512）、`parent_id`（null 表示移到根级）
**响应 Model：** `SpaceResp`
> 权限：仅创建者可更新（`403`）；默认空间仅 admin 可改名、不支持移动（`409`）。
> 防环校验：不能移动到自己的下级或子孙节点下（`409`）；`code` 与默认标记不可改。

### 4.4 删除空间
`DELETE /v1/spaces/{space_id}` → `{"deleted": "<space_id>"}`
> 权限：仅创建者可删除（`403`）。
> 保护策略（均 `409`）：默认空间不可删；空间内仍有文档不可删；下仍有子空间不可删。

## 5. 文档接入（/v1/documents）

### 5.1 单篇接入（内联正文）
`POST /v1/documents/ingest` — 需认证（scopes 含 `documents` 或 `*`）

**请求体（DocumentIngest）：** 字段见 2.1（`external_id`/`title`/`doc_type` 必填）。
**响应 Model（IngestResp，HTTP 200）：**
| 字段 | 类型 | 说明 |
|---|---|---|
| external_id | string | 第三方主键（幂等键，重复接入不重复入库） |
| document_id | string | 平台文档 ID |
| status | string | `indexed` / `duplicate` 等 |
| chunk_count | int | 切片数 |
| message | string | 附加说明 |

> **空间所有权（2026-10-14）**：`space_id` 指定时必须为本人可见空间（默认公共空间或本人创建），他人空间 `403`；缺省归入默认空间。

### 5.2 文件上传接入（PDF/DOCX，异步）
`POST /v1/documents/upload` — 需认证；`multipart/form-data`

**表单字段：**
| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| file | file | —（必填） | PDF/DOCX 文件 |
| external_id | string | 文件名 | 第三方主键 |
| title | string | 文件名 | 标题 |
| doc_type | string | `通知` | 文种 |
| issuer / doc_no / publish_date | string | 空 | 元数据 |
| security_level | enum | `INTERNAL` | 密级 |
| permission_tags | string | 空 | 逗号分隔，如 `scope:dept:总部,scope:role:公文员` |
| space_id | string | 空 | 目标空间；缺省归入默认空间。**仅限默认公共空间或本人创建空间**（他人空间 `403`） |
| chunk_strategy | enum | `paragraph` | 切分策略 |
| chunk_size / chunk_overlap | int | 800 / 80 | 切片参数 |

**响应 Model（IngestionJobResp，HTTP 200）：** 入库任务（含状态机进度，前端轮询 5.4）。
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 任务 ID |
| filename | string | 文件名 |
| status | string | `PENDING`/`PARSING`/`CHUNKING`/`EMBEDDING`/`INDEXED`/`FAILED` |
| progress | int | 0–100 百分比 |
| total_chunks / processed_chunks | int | 切片进度 |
| error_message | string \| null | 失败原因 |
| document_id | string \| null | 完成后关联的文档 ID |
| strategy / chunk_size / chunk_overlap / security_level | — | 切分与密级参数回显 |
| created_at / updated_at | datetime \| null | 时间戳 |

> **任务所有权（2026-10-14）**：入库任务按提交者隔离——`GET /v1/documents/jobs` 仅返回本人任务；他人任务 ID 查询返回 `404`。

### 5.3 文档库列表（管理视图）
`GET /v1/documents` — 需认证

**Query 参数（均选填）：** `doc_type`、`security_level`、`space_id`、`status`（过滤）；`q`（标题/文号模糊检索）；`page`（默认 1）、`size`（默认 20，≤200）。
**响应 Model（DocumentSummary[]）：**
| 字段 | 类型 | 说明 |
|---|---|---|
| id / external_id | string | 平台 ID / 第三方主键 |
| title / doc_type / issuer / doc_no | string | 基本信息 |
| security_level | enum | 密级 |
| permission_tags | string[] | 权限标签 |
| space_id / space_name | string \| null | 所属空间 ID / 名称 |
| status | string | 文档状态 |
| chunk_count | int | 切片数 |
| created_at | datetime \| null | 创建时间 |

> **空间所有权（2026-10-14）**：列表/统计/详情仅覆盖本人可见空间内的文档（默认公共 + 本人创建）；他人空间文档不可见（详情 `404`）。

### 5.4 统计 / 入库任务
- `GET /v1/documents/stats?space_id=<可选>` → **DocStats**：`{ total_documents: int, total_chunks: int, by_status: {状态:数量}, by_security: {密级:数量} }`（仅统计本人可见空间）
- `GET /v1/documents/jobs?limit=20` → `IngestionJobResp[]`（最近任务，**仅本人提交**）
- `GET /v1/documents/jobs/{job_id}` → `IngestionJobResp`（实时状态；不存在或非本人任务均 `404`）

### 5.5 文档详情（含切片）
`GET /v1/documents/{doc_id}` — 需认证

**响应 Model（DocumentDetail）：** DocumentSummary 全部字段 + `publish_date`（datetime）、`owner_org`、`source_system`、`chunks`（ChunkInfo[]：`seq`/`content`/`security_level`/`tokens`）。不存在或空间不可见均 `404`。

## 6. 检索（/v1/retrieve）

`POST /v1/retrieve` — 需认证（scopes 含 `retrieve` 或 `*`）

**请求体（RetrieveRequest）：**
| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| query | string | 是 | — | 检索问题 |
| doc_types | string[] | 否 | null | 限定文种 |
| space_ids | string[] | 否 | null | 限定文档空间（多选）；**仅可纳入本人可见空间**（默认公共 + 本人创建），他人空间 `403` |
| top_n | int | 否 | 8 | 返回条数 |
| caller_scope | string[] | 否 | [] | 调用方权限标签（见 2.3） |
| max_clearance | enum | 否 | `INTERNAL` | 请求密级上限（服务端按调用方额度压低） |
| rerank | bool | 否 | true | 是否启用重排 |

**响应 Model（RetrieveResp，HTTP 200）：**
| 字段 | 类型 | 说明 |
|---|---|---|
| query | string | 回显检索问题 |
| citations | Citation[] | 命中列表（已做密级/权限下推过滤） |
| total_matched | int | 命中总数 |
| truncated_by_security | bool | 是否存在因密级/权限被过滤的结果 |
| top_vector_distance | float \| null | 向量路 top1 余弦距离（"无有用信息"判定信号） |
| keyword_hits | int | 关键词路命中数 |

**Citation Model：** `{ chunk_id: string, document_id: string, title: string, doc_no: string|null, snippet: string, score: float }`

```json
{
  "query": "安全生产责任追究",
  "citations": [
    { "chunk_id": "c-123", "document_id": "d-1", "title": "关于...的通知",
      "doc_no": "XX函〔2025〕12号", "snippet": "...", "score": 0.91 }
  ],
  "total_matched": 3, "truncated_by_security": false,
  "top_vector_distance": 0.31, "keyword_hits": 3
}
```
> 密级/权限过滤在检索阶段服务端 WHERE 下推；过滤后为空返回空列表（非 403）。

## 7. 推理 / 问答 / 起草

### 7.1 非流式生成（起草辅助）
`POST /v1/generate` — 需认证（scopes 含 `chat` 或 `*`）

**请求体（GenerateRequest）：**
| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| query | string | 是 | — | 问题 / 起草要求 |
| doc_types | string[] | 否 | null | 限定文种 |
| space_ids | string[] | 否 | null | 限定空间（多选） |
| caller_scope | string[] | 否 | [] | 权限标签 |
| max_clearance | enum | 否 | `INTERNAL` | 密级上限（被调用方额度压低） |
| template_doc_type | string | 否 | null | 按文种模板起草（通知/报告/…） |
| template_code | string | 否 | null | 精确指定同类多模板中的某一个（模板编码，见 10 章模板库）；缺省按 `template_doc_type` 取该文种首个启用模板；两者都缺省则不注入模板 |
| conversation_id | string | 否 | null | 所属会话（多轮修改）；缺省自动创建 |
| sensitive_words | string[] | 否 | null | 请求级敏感词覆盖；缺省用配置中心词库 |
| rerank | bool | 否 | false | 起草链路默认关重排（避免久等） |
| agent_mode | bool | 否 | null | Agent 模式（意图路由+分步执行）；null=按配置中心开关（默认开），false 强制纯直答 |
| stream | bool | 否 | false | 兼容字段，流式请用 7.2 |

**响应 Model（GenerateResp，HTTP 200）：**
| 字段 | 类型 | 说明 |
|---|---|---|
| answer | string | 答案 / 草稿正文 |
| citations | Citation[] | 引用列表（同 6 章 Citation） |
| sensitive_hits | string[] | 敏感词命中（已脱敏） |
| model | string | 生成模型名 |
| truncated_by_security | bool | 是否有结果被密级/权限过滤 |

### 7.2 流式生成（SSE，起草）
`POST /v1/generate/stream` — 需认证；请求体同 GenerateRequest（忽略 `stream` 字段）。

**SSE 事件序列（`data: {json}\n\n`）：**
| type | 字段 | 说明 |
|---|---|---|
| `meta` | `model, conversation_id, truncated_by_security, agent_mode, intent, intent_label, no_result, citations[]` | 检索完成，先回传上下文与 Agent 意图 |
| `token` | `text` | 正文逐片 |
| `reasoning` | `text` | 思考链片段（推理模型，可选） |
| `done` | `answer, sensitive_hits[], model, conversation_id, intent, no_result, disclaimer` | 收尾（含脱敏后完整答案；disclaimer=无材料兜底的甄别声明） |
| `error` | `message` | 异常（`{异常类型}: {摘要}`） |

### 7.3 智能问答流式（SSE，多轮）
`POST /v1/chat/stream` — 需认证（scopes 含 `chat` 或 `*`）

**请求体（ChatRequest）：**
| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| conversation_id | string | 否 | null | 会话 ID；为空时自动创建（meta/done 回传） |
| query | string | 是 | — | 问题 |
| space_ids | string[] | 否 | null | 本次问答限定空间；缺省沿用会话绑定空间 |
| doc_types | string[] | 否 | null | 限定文种 |
| caller_scope | string[] | 否 | [] | 权限标签 |
| max_clearance | enum | 否 | `INTERNAL` | 密级上限（被调用方额度压低） |
| top_n | int | 否 | 8 | 检索条数 |
| rerank | bool | 否 | true | 问答链路默认启用重排 |
| agent_mode | bool | 否 | null | 同 7.1 |
| sensitive_words | string[] | 否 | null | 请求级敏感词覆盖 |

**SSE 事件序列：**
| type | 字段 | 说明 |
|---|---|---|
| `meta` | `conversation_id, model, intent, intent_label, agent_mode, no_result, citations[]` | 会话与检索元数据 |
| `plan` | `steps[{id, action(retrieve/generate), query, status}], channel` | 复杂任务拆步计划（过程可见） |
| `step_start` | `id, action, query` | 某步骤开始 |
| `step_end` | `id, ok, summary` | 某步骤结束（ok=false 时 summary 为失败原因） |
| `token` | `text` | 正文逐片 |
| `reasoning` | `text` | 思考链片段（可选） |
| `done` | `answer, sensitive_hits[], model, conversation_id, intent, no_result, disclaimer` | 收尾 |
| `error` | `message` | 异常 |

> Agent 模式（默认开）先做意图路由（direct_qa/complex_task/draft/chitchat/out_of_scope）再分发策略；老客户端忽略新事件即可兼容。用户点「停止」时后端自动保存已生成部分为助手消息。

## 8. 会话（/v1/conversations）

> 智能问答（chat）与公文起草（draft）共用会话体系；多轮上下文由后端在生成时自动拼接。

- `POST /v1/conversations` — 需认证。**请求体（ConversationCreate）：** `conv_type`（`chat`/`draft`，默认 `chat`）、`title`（≤256）、`space_ids`（绑定的知识空间，**仅限本人可见空间**，他人空间 `403`）。**响应：** `ConversationResp`（HTTP 201）。
- `GET /v1/conversations?conv_type=&limit=50` → `ConversationResp[]`（按最后活跃倒序）。
- `GET /v1/conversations/{id}` → **ConversationDetail**（ConversationResp + `messages`：MessageResp[]）。`404` 不存在。
- `PUT /v1/conversations/{id}` — **请求体（ConversationUpdate）：** `title`、`space_ids`（均选填；新绑定空间同样限本人可见，`403`）。**响应：** `ConversationResp`。
- `DELETE /v1/conversations/{id}` → `{"deleted": "<id>"}`（消息级联删除）。
- `POST /v1/conversations/{id}/messages` — 手动追加消息。**请求体（MessageAppend）：** `role`（`user`/`assistant`，默认 `assistant`）、`content`（必填）、`citations[]`、`sensitive_hits[]`、`model`、`intent`、`reasoning`。**响应：** `MessageResp`（HTTP 201）。

**ConversationResp Model：** `{ id, title, conv_type, doc_type: string|null, space_ids: string[], message_count: int, last_message_at: datetime|null, created_at, updated_at }`
**MessageResp Model：** `{ id, role, content, citations: object[], sensitive_hits: string[], model: string|null, intent: string|null, reasoning: string|null, created_at }`
（`reasoning` = 模型思考链全文，回答结束后保留可查；`intent` = Agent 意图标识留痕；`doc_type` = 起草会话绑定的文种，由首次生成时解析模板后自动写入，供前端打开历史时还原文种与模板选择。）

## 10. 模板库（/v1/templates）

> 我方维护 8 类标准公文模板（开箱即用）；支持第三方上传导入（解析正文→识别文种→提取章节结构）。
> **同一文种支持配置多个模板**（如多种「通知」）：`key` 为模板编码 `code`（全局唯一），`value.doc_type` 表示所属文种；
> 起草时可用 `template_code` 精确选用某一类（见 7.1），缺省取该文种首个启用模板。

> **所有权隔离（2026-10-14，与文档空间同一套规则）：**
> - 系统标准模板（种子 8 类，`value.owner_type="system"`）：**所有人可见、可引用起草**，仅 admin 可维护（`POST`/`DELETE` 返回 `403`）；
> - 用户/第三方上传或新建的模板：**仅创建者本人可见**（列表/下载）、可编辑、可删除；他人列表中不可见，引用其 `code` 起草时 `403`；
> - 响应 `value` 携带 `owner_type / owner_id / owner_name / is_mine / can_edit`，前端据此展示归属并开放/收起维护按钮。

- `GET /v1/templates` — 需认证。**响应：** `ConfigItem[]`，每项 `{ category:"template", key:<模板编码 code>, value:{ doc_type, name, layout, content_ref, owner_type, owner_id, owner_name, is_mine, can_edit } }`（按归属 + 文种 + 创建时间排序；仅返回系统模板 + 本人模板）。
  **layout 结构：** `{ red_head: bool, font: string, paper: string, subtitle: string, tone: string, sections: [{key, label, placeholder, required}] }`
- `POST /v1/templates` — 需认证。**请求体（ConfigItem）：** `category="template"`、`key=<模板编码 code>`、`value={doc_type, name, layout}`（文种/红头/字体/纸张/章节）。**响应：** 创建或更新后的 ConfigItem（code 已存在则更新其版式）。**所有权：** 新建归属当前调用方；更新他人模板或系统标准模板 → `403`（系统模板限 admin）。
- `POST /v1/templates/upload` — 需认证；`multipart/form-data`：`file`（docx/pdf/txt）、`doc_type`（可空，自动识别）、`name`。每次上传作为**独立新模板**（自动生成 code，不覆盖同文种已有模板），**归属上传方**。**响应：** ConfigItem。
- `GET /v1/templates/{code}/file` — 需认证。下载该模板的上传原件（文件流；无上传文件时 `404`；他人模板不可见 → `404`）。
- `POST /v1/templates/seed` — 需认证，**限 admin**。手动初始化标准模板库（幂等，不覆盖已有模板）→ `{"added": int, "message": string}`。
- `DELETE /v1/templates/{code}` — 需认证 → `{"deleted": bool}`。仅创建者可删除本人模板；系统标准模板限 admin；他人模板 → `403`。

## 12. 配置接口（/v1/config）

> 配置中心按 category/key/value 存储（敏感词、格式适配器、模型 Profile、检索参数、提示词模板等），前端结构化表单读写，不接触原始 JSON。所有配置**保存即时生效**，无需重启。

- `GET /v1/config/items?category=<分类>` — 需认证 → `ConfigItem[]`。
  **ConfigItem Model：** `{ category: string, key: string, value: object, scope: string|null, is_active: bool }`
- `PUT /v1/config/items` — 需认证。**请求体：** ConfigItem（按 category+key upsert）。**响应：** 保存后的 ConfigItem。
- `DELETE /v1/config/items?category=<分类>&key=<键>` — 需认证 → `{"deleted": bool, "category": "...", "key": "..."}`。

**标准分类（category）一览：**

| category | 内容 | 典型 key |
|---|---|---|
| `sensitive_word` | 敏感词词条（命中自动脱敏） | 词条本身，value=`{severity, note}` |
| `format_adapter` | 文件格式适配器 | 名称，value=`{extensions[], priority}` |
| `model_profile` | 模型接入档案 | 名称，value=`{type, endpoint, api_key, model}` |
| `dict_custom` | 自定义词典（术语标准化映射） | 词条，value=`{mapping}` |
| `agent` | Agent 运行参数 | `enabled`/`llm_classify`/`llm_classify_timeout_ms`/`max_steps`，value=`{value}` |
| `retrieval` | 检索参数（启动种子 9 项，见 `services/runtime_config.py`） | `final_top_n`/`vector_top_n`/`keyword_top_n`/`rerank_enabled`/`vec_distance_threshold`/`rerank_min_score`/`rewrite_enabled`/`rewrite_max_rounds`/`rewrite_timeout_ms`，value=`{value}` |
| `prompt` | 生成提示词模板 | `draft_system`/`no_materials_system`/`chat_system`/`chat_no_materials_system`，value=`{value: 模板文本}` |

> 读取规则：服务端每次请求实时读取（is_active=true 生效）；缺项/停用/解析异常一律回退代码默认值（配置问题不影响主链路）。`retrieval` 类由启动种子写入默认值（幂等，不覆盖用户已改值）；`prompt` 类不种子，未配置时用 `services/generation_prompt.py` 内置文案。
> 相关度阈值语义：`vec_distance_threshold` 为「无有用信息」双信号判定的向量距离线（top1 距离超限且关键词零命中才判定）；`rerank_min_score` 为 rerank top1 分数有效线（查询改写触发条件之一，随《检索优化方案 V1.0》P1 上线参与判定）。

## 14. 错误码标准

> 错误响应体统一为 `{"detail": "<描述>"}`；业务成功码 200（创建类 201）。

| HTTP | 含义 | 典型 detail |
|---|---|---|
| 200 | 成功 | — |
| 201 | 创建成功 | — |
| 400 | 参数缺失/非法 | 字段校验失败（Pydantic 详情） |
| 401 | 鉴权失败 | `需要登录凭证（Bearer JWT）或 API Key（X-API-Key）` / `用户名或口令错误` / `API Key 无效或已禁用` / `API Key 已过期` / `未登录或登录已过期` |
| 403 | 越权 | `该客户端无 <域> 能力域权限` / `需要管理员权限` |
| 404 | 资源不存在 | `文档不存在` / `会话不存在` / `客户端不存在` / `文档空间不存在：<id>` |
| 409 | 冲突 | `external_id 重复` / `空间编码已存在：<code>` / `默认空间不可删除` / `空间内仍有 N 篇文档…` / `不能把空间移动到自己的子孙节点下` |
| 422 | 解析/格式失败 | 文档解析或格式适配失败 |
| 429 | 限流 | — |
| 500 | 内部错误 | — |
| 503 | 模型后端不可用 | 算力中心未就绪 |

## 15. 健康检查与联调

- `GET /health`（开放）→ `{ "status": "ok", "version": "<版本>", "environment": "dev|prod" }`
- 交互式文档：`GET /docs`（Swagger UI）、`GET /redoc`、`GET /openapi.json`（开放，联调必备）。

**最小联调链路（第三方）：**
1. `POST /v1/auth/clients/register` → 保存 `api_key`（一次性）；
2. `POST /v1/documents/ingest`（带 `X-API-Key`）接入文档；
3. `POST /v1/retrieve` / `POST /v1/chat/stream` 检索与问答；
4. `POST /v1/export/docx` 导出。

**最小联调链路（运维台用户）：**
1. `POST /v1/auth/login` → 保存 JWT；
2. 全部业务端点带 `Authorization: Bearer <JWT>`；
3. admin 用户可访问 `/v1/auth/clients` 管理第三方客户端。

> M6 联调建议按本章顺序逐项确认；字段/枚举/模型接口以本文与 `contracts.py` 为准。
