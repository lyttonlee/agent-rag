## 1. 架构目标与原则

1. **标准先行**：接口、字段、密级/权限枚举、模型接入由平台制定标准，集成方适配。
2. **模块化单体**：单一部署单元、内部分层；200 用户/20 并发无需微服务。
3. **模型可替换**：`ModelProvider` 抽象，默认本地栈 / 云端 API / 部署方算力中心（标准接口）三类后端。
4. **权限过滤前置**：密级/权限在检索阶段服务端下推，不进模型上下文。
5. **涉密不出网**：Provider 隔离 + 启动自检 + 网络封死出口三层防护。

## 3. 组件职责

| 组件 | 职责 |
|---|---|
| 文档接入服务 | 接收第三方推送/批量投放；校验字段标准；触发异步入库 |
| 格式适配 | 按配置适配不同公文系统导出布局（字段映射/识别规则） |
| 解析/切片 | PDF(docx/wps) 解析、结构化抽取、清洗、语义切片+上下文前缀 |
| Embedding 流水线 | Qwen3-Embedding-4B 向量化（离线/批量，定后不换） |
| 存储/索引 | PG 存 document/chunk（含 vector/tsvector/密级/权限标签）；HNSW + tsvector 索引 |
| 检索服务 | 关键词(tsvector+zhparser)+向量(HNSW)→RRF→权限下推→Rerank-0.6B |
| 生成编排 | 检索增强+模板装配+Qwen3-32B 生成+引用标注+敏感词后处理 |
| 模板引擎 | 管理 8 类文种模板（我方维护，支持第三方导入）；套用渲染 |
| 导出服务 | 按模板渲染 docx/pdf，提供下载接口 |
| 敏感词引擎 | 配置词集 + 请求级覆盖；生成输出 masking/flag |
| 权限与合规 | 执行密级/权限过滤（按我方标准）；审计 |
| 配置中心 | 敏感词/格式适配/模板/模型接入(ModelProfile) 配置 |
| 运维后台 | 入库监控、评测、配置管理（Vue3） |

## 4. 关键数据流

### 4.1 入库流
```
第三方(按字段标准带密级/权限) → 接入网关 → 文档接入(校验) → 格式适配 → 解析/切片
   → Embedding → PG(存密级/权限标签+向量+tsvector) → 索引 → 运维台可见状态
```

### 4.2 检索流
```
第三方(query + caller_scope + max_clearance) → 网关 → 检索服务
   → 关键词召回 + 向量召回 → RRF → [权限下推: permission_tags∩caller_scope AND level≤max]
   → Rerank-0.6B → top-K(已过滤) → 返回 citations
```

### 4.3 生成/导出流
```
第三方(generate: task,doc_type,query,elements,context) → 生成编排
   → 检索(带过滤) → 模板装配 → Qwen3-32B 生成 → 引用标注 → 敏感词后处理
   → 返回 {answer, citations, sensitive_hits}
   → (可选) 导出: 选模板 → 渲染 docx/pdf → 下载接口返回文件
```

## 7. 跨切面设计

- **安全**：调用上下文信任上游；密级/权限服务端下推；敏感词后处理；审计全留痕；禁止出网。
- **配置**：配置中心管理敏感词/格式适配/模板/ModelProfile；热加载。
- **多部署级别**：每部署实例一套 ModelProfile 配置；默认栈兜底；标准接口接入第三方算力中心。
- **可观测**：入库进度、检索延迟(P95)、生成耗时、幻觉率、审计日志，运维台呈现。
- **信创**：OS/DB 国产可替换；GPU 不受限。
